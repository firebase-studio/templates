# Next.js Skill

This skill bootstraps a new Next.js application using `create-next-app`.

It allows for customization through parameters, mirroring the options provided by the official Next.js command-line tool.

## Parameters

-   `projectName`: The name of the project directory to create.
-   `language`: Use TypeScript (`ts`) or JavaScript (`js`).
-   `appRouter`: Use the App Router (`true`) or the Pages Router (`false`).
-   `srcDir`: Place application code in a `src/` directory.
-   `tailwind`: Set up the project with Tailwind CSS.
-   `eslint`: Set up the project with ESLint.

## Usage

This skill can be invoked by development environments like Antigravity to automate the creation of a new Next.js project.
