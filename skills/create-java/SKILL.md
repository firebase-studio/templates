# Java Skill

This skill defines a simple Spring Boot web application.

## Skill Name

create-java

## Description

A simple Spring Boot web application that provides a customizable greeting.

## Files

This skill is composed of the following files:

*   `pom.xml`: The Maven project configuration file.
*   `src/main/java/com/example/demo/DemoApplication.java`: The main application source code.
*   `src/main/resources/application.properties`: The application configuration file.
*   `src/test/java/com/example/demo/DemoApplicationTests.java`: The test source code.

## Commands

### Run the application

```bash
mvn spring-boot:run
```

### Test the application

```bash
mvn test
```
