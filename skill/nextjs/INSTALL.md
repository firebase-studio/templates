# Manual Installation Guide for Next.js Project

This guide explains how to manually set up a Next.js project, similar to the one created by this template.

## 1. Create a new Next.js app

You can use `create-next-app` to create a new Next.js project.

```bash
npx create-next-app@latest my-next-app
```

## 2. Navigate to your project directory

```bash
cd my-next-app
```

## 3. Start the development server

```bash
npm run dev
```

Your Next.js app is now running at `http://localhost:3000`.
